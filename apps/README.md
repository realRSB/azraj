# Azraj Apps

This repo is moving toward a monorepo layout:

- `apps/web` - public signup and future user dashboard.
- `apps/desktop` - placeholder for the existing Electron shell in `../../electron`.
- `apps/mobile` - placeholder for a future mobile app.
- `server` and `convex` - the current backend runtime and data layer.

The desktop and backend folders are not moved yet so the current local agent setup keeps working.
