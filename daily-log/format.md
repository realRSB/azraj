# Daily Log Format

Use one Markdown file per person per day:

```text
daily-log/<person>/<YYYY-MM-DD>.md
```

## Template

```md
# Daily Log - YYYY-MM-DD

Owner: Name

## Summary

One or two sentences describing the main focus of the day.

## Work Completed

- Completed item 1.
- Completed item 2.

## Validation

- Checks, tests, reviews, or smoke tests that passed.

## Blockers

- Anything still blocked or needing follow-up.

## Next Steps

- The next concrete action.

## Notes

- Extra context worth preserving.
```
